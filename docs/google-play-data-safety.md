# Google Play — Data Safety и background location

Заполнять форму по фактической production-сборке.

## Данные

| Категория | Собирается | Связано с аккаунтом | Назначение |
| --- | --- | --- | --- |
| Имя, телефон, user ID | Да | Да | Аккаунт и выполнение заказа |
| Точная геолокация | Да | Да | Карта, подбор и сопровождение заказа |
| Адреса | Да | Да | Поездки и доставка |
| Фото и документы водителя | Да | Да | Профиль и проверка исполнителя |
| Сообщения | Да | Да | Связь и безопасность |
| История заказов | Да | Да | Выполнение, поддержка и история |
| Push token | Да | Да | Статусные уведомления |
| Диагностика/Sentry | Только если включён DSN | Обычно нет | Стабильность |

- Данные не используются для межсервисного рекламного tracking.
- Карточные данные не собираются: food beta использует наличные/Kaspi напрямую.
- Передача участникам заказа ограничивается данными, необходимыми для выполнения.
- Шифрование в пути: только HTTPS/WSS; Android cleartext отключён.
- Удаление доступно внутри приложения и через публичную web-страницу.

## Prominent disclosure

Показывается перед системным запросом, когда водитель нажимает «На линии»:

> Когда вы нажимаете «На линии», TaxiVillage передаёт вашу геопозицию клиенту и
> серверу, чтобы показывать ближайшие заказы и движение к адресу. Отслеживание
> продолжается в фоне только пока вы на линии. После перехода офлайн оно
> останавливается.

Для Play Console записать видео:

1. открыть экран водителя;
2. нажать «На линии»;
3. показать disclosure;
4. продолжить и показать системный запрос;
5. принять заказ;
6. свернуть приложение и показать обновление позиции;
7. перейти офлайн и показать остановку tracking.
