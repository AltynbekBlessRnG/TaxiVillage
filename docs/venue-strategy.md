# TaxiVillage Places — продуктовая стратегия заведений

## Позиционирование

Не строить ещё один каталог ресторанов. В небольшом населённом пункте сильнее работает «единое окно деревни»: пользователь открывает TaxiVillage не только когда нужна машина, а когда нужно что-то получить сегодня.

Главная формула:

> Местные места + знакомые исполнители + доставка по деревне в одном заказе.

## Какие заведения подключать

Начать не только с кафе:

- домашняя кухня, пекарни и кондитеры;
- продуктовые и хозяйственные магазины;
- аптеки с резервом товара без продажи рецептурных препаратов в приложении;
- цветы, подарки и товары для праздников;
- фермеры: молоко, мясо, яйца, овощи;
- шиномонтаж, автомойка и СТО с записью;
- парикмахеры и мастера с бронированием времени;
- газовые баллоны, питьевая вода и другие регулярные доставки.

## Отличие от больших delivery-приложений

### 1. «Привези по пути»

Водитель или курьер видит заказы, которые лежат по маршруту. Это снижает стоимость доставки при малом количестве исполнителей.

### 2. Общая корзина деревни

Пользователь собирает один список из нескольких мест: хлеб из пекарни, лекарства из аптеки, продукты из магазина. Система группирует точки в маршрут и показывает общую цену доставки.

### 3. Заказ без цифрового меню

Для маленьких продавцов достаточно:

- фотографии витрины;
- голосового или текстового списка;
- кнопки «повторить прошлый заказ»;
- подтверждения продавцом наличия и итоговой цены.

Так подключение занимает один вечер, а не неделю заполнения каталога.

### 4. «Есть сегодня»

Лента коротких предложений с реальным остатком:

- горячий хлеб после 17:00;
- свежее молоко сегодня;
- свободное окно мастера;
- обед дня;
- доставка воды по конкретному району.

Предложение автоматически исчезает после срока или исчерпания количества.

### 5. Доверие вместо анонимного рейтинга

Показывать:

- сколько лет место работает;
- сколько заказов выполнено в TaxiVillage;
- скорость подтверждения;
- «проверено TaxiVillage»;
- отзывы только после реального заказа.

## Первый MVP

Первая версия Places должна содержать:

1. Категории мест.
2. Статус «открыто / принимает предзаказы».
3. Быстрые предложения «сегодня».
4. Обычный каталог либо свободный список заказа.
5. Подтверждение наличия и итоговой суммы заведением.
6. Выбор: заберу сам / доставит TaxiVillage.
7. Повтор заказа.
8. Один чат заказа, без перехода в WhatsApp.

## Монетизация

Для старта не брать высокий процент:

- бесплатное подключение;
- фиксированная плата с выполненной доставки;
- недорогая месячная подписка «Партнёр» за витрину, статистику и продвижение;
- продвижение конкретного предложения на 24 часа;
- комиссия только с подтверждённого заказа, если платёж проходит через платформу.

## Метрика успеха

Главная метрика — не число ресторанов, а количество жителей, которые делают хотя бы один нетранспортный заказ в неделю.

Дополнительные:

- время подтверждения заведением;
- доля повторных заказов;
- доля доставок «по пути»;
- среднее число точек в объединённом заказе;
- отмены из-за отсутствия товара.

## План запуска в одном населённом пункте

1. Лично подключить 5–8 разных мест, а не 20 одинаковых кафе.
2. Для каждого создать 3–5 предложений «сегодня».
3. Первые две недели не требовать полного каталога.
4. Дать жителям бесплатную первую объединённую доставку.
5. Каждую неделю показывать местам простую статистику: просмотры, заказы, повторы.
6. После появления устойчивого спроса убрать WhatsApp из основного заказа и оставить его только как резервный канал поддержки.
